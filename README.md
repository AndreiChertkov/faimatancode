# faimatancode


## Описание

Репозиторий faimatancode (**F**aculty of **A**rtificial **I**ntelligence; **MAT**hematical **AN**alysis; **CODE**) содержит в папках `textbook1` и `workbook1` программный код, представленный в учебнике "Математический анализ" (А.В. Чертков, И.В. Оселедец) и задачнике "Сборник задач по математическому анализу" (А.А. Вихров, И.В. Оселедец, Е.Ю. Севрюгов, А.В. Чертков) соответственно.
